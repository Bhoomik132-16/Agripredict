# 📊 Mathematical Guide for Crop Prediction

This guide provides the formulas behind the AgriPredict AI engine, allowing for manual verification of results.

## 1. Input Normalization (Z-Score)
Before processing, every input $X$ is standardized using:
$$Z = \frac{X - \mu}{\sigma}$$

| Parameter | Mean ($\mu$) | Std Dev ($\sigma$) |
| :--- | :--- | :--- |
| Nitrogen (N) | 76.62 | 20.09 |
| Phosphorus (P) | 33.50 | 11.56 |
| Potassium (K) | 32.24 | 7.92 |
| pH Level | 6.64 | 0.69 |

## 2. Yield Approximation Formula
To verify the **Predicted Yield (Tons)**, you can use this linear approximation:
$$\text{Yield} \approx 2.5 + (Z_N \times 1.2) + (Z_P \times 0.05) + (Z_{Rain} \times 0.5)$$

*   **Positive $Z$:** Adds to the yield (Condition is above average).
*   **Negative $Z$:** Subtracts from the yield (Condition is below average).

## 3. Decision Logic (If-Then)
The AI is a **Random Forest** (100 Trees). It uses thresholds like:
- **IF** Rainfall < 1000mm **AND** Crop == "Rice" **THEN** Yield Penalty = 50%
- **IF** N > 100 **AND** Soil == "Alluvial" **THEN** Yield Bonus = 20%
